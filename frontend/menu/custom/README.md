# 自定义 / 订阅源（`menu/custom/`）

- **这块菜单管什么**：3 条二级条目——手动映射、GitHub520、china-hosts。
- **条目从哪来**：写在本文件夹 `module.js` 的 `items` 里，逐字搬自原型 :1132 那一段；加一条只改这里，别的文件夹一个字不动。
- **谁能用它**：只有 `views/menu/` 那一份渲染器读它（那是 F5，还没建）。本文件夹不许出现 `document.`、`innerHTML`，也不许 import `views/` 里的东西——第 4 节那两条 grep 管着。
- **原型没说的这里不替它编**：「检测参数」「还原口径」在原型里是全局一套，不是每块菜单各一套；`module.js` 因此只有名字/顺序/条目三样。

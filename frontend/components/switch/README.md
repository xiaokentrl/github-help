# Switch（`components/switch/`）

- **这个件管什么**：只表示"改了立刻生效的全局偏好"。状态：开、关、悬停、焦点可见、禁用（禁用要有原因，那句原因由调用方传 `title`，件挂到开关本体上；`setDisabled(true)` 同样管两件事：input 灰 + title 上）。
- **有哪些状态靠谁给**：给读屏的状态字（"已开启／已关闭"这类）由调用方通过 `onText`/`offText` 传进来——件里不许刻中文（8.3）。语义跟 Checkbox 不许混用：那一件管"这一条要不要纳入本次操作"。
- **谁在用**：设置中心那 8 处（原型 :943-946 已经是真 input + label 包住整行，这一件就是照它收的）。

# Button（`components/button/`）

- **这个件管什么**：普通 / 主操作（`primary`）／危险（`danger`）／弱化（`ghost`）四型，常规 30 px 与小尺寸 24 px 两档；状态有默认、悬停、按下、焦点可见、禁用、加载中。
- **有哪些状态靠谁给**：禁用与加载中要说清"在等什么"，那句话说什么由调用方通过 `title` 传进来——件里不许刻中文（8.3）。焦点环不在这里画，走 `styles/base.css` 那一条全站统一的 `:focus-visible`。
- **谁在用**：工具栏、队列行、弹窗底栏、设置面板都用它（`views/**` 与行级件）。类名照原型 `.btn/.btn-sm/.primary/...`，所以那份基线 HTML 原样复用也接得上。

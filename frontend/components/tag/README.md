# Tag（`components/tag/`）

- **这个件管什么**：短促状态字。四档：`green`（候选表那颗「最优」，原型 `.tag`）、`detect` / `apply` / `restore`（队列行的任务类型小标，原型 `.q-kind`）。状态：只有默认态——它是标签，不是按钮，不点。
- **有哪些状态靠谁给**：文字由调用方给 `text`；`size:'md'` 是新用例那一档（11px 起），不传就是照原型的 10px 旧档（`--fs-legacy-tag`，第 10 节第 3 条已定"这两族不动"）。字色走配对变量 `--on-green`，所以樱花粉那套压深绿用的是深梅色而不是白字——这一处以前靠五套主题各写一条点名覆盖，现在不用。
- **谁在用**：候选表「最优」（原型 :1923）、队列行任务类型（:2106-2107、:2157-2158，同一句在两处各写一遍的老账由 `views/queue/parts/QueueRow.js` 收成一处）。

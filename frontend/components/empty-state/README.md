# EmptyState（`components/empty-state/`）

- **这个件管什么**：没数据／没结果／没选中时那一句人话。三档内容必须齐：标题 + 一句提示（可省）+ **一个可点的下一步**。两档形状：`panel`（详情那块，铺满高度、带 52×52 的图标位，原型 :199-201）、`inline`（树里、队列里那一条矮的，原型 :89）。
- **有哪些状态靠谁给**：标题、提示、按钮上的字与点了做什么，全部由调用方传（`title`／`hint`／`action:{label,onClick}`），件里一个中文也不写——三处空态的文案将来都走 `t()`（8.3 那条）。不给 `action` 当场抛错，为的是别让第三处又漏掉那颗按钮（这正是原型三处各写各的病）。
- **谁在用**：三处（原型 :1831 树"没有匹配的类目或域名"、:1907 详情"请选择左侧任意项"、:2136 队列"队列为空"）。文案键各一处，件只一个。

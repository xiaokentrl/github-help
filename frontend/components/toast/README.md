# Toast（`components/toast/`）

- **这个件管什么**：屏幕底部中间那一句"刚才发生了什么"。四档语气：`info`／`ok`／`warn`／`error`。状态：出现（`.show` + 上移淡入）／悬停暂停／自动收／**报错类不自动收，必须点掉**。位置底中、层级 `--z-toast`(99)、圆角 `--radius-bubble`(7px) 全照原型 :431。
- **有哪些状态靠谁给**：句子由调用方传 `text`；报错类那颗动作按钮的字（"复制错误码"这类）与点掉那颗的悬停说明也由调用方传（`actionText`／`closeText`），按下去做什么走 `onCopy` 回调——件里不持有文案也不管业务。时长不用调用方算：`toastMs()` 按字数给（24 字以内 2200ms＝原型原值，长文案 4s 起，最多 9s）；`duration` 只用于非报错类想指定时长的场合。
- **谁在用**：原型有 76 个 `showToast(` 调用点，全都吃那个写死的 2200ms——这一件把时长与"报错不许自动消失"收在一处。整个应用建一个（挂在 `body` 末尾），别按菜单各建一个。

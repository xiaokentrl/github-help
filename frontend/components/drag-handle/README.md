# DragHandle（`components/drag-handle/`）

- **这个件管什么**：拖着改尺寸的那道把手。两档：`axis:'x'`（侧栏那道 6px 宽，原型 `.sidebar-resizer` :96-99）、`axis:'y'`（队列那道 6px 高，原型 `.resizer` :193-196，往上拖变高，方向在这一个件里算）。状态：默认／悬停（变主色）／拖动中（`.dragging`，同样变主色）／键盘聚焦（焦点环由 `styles/base.css` 全站那条画）。
- **有哪些状态靠谁给**：上下限由调用方传 `min`/`max`（件内每次都钳，"拖过去回不来"不可能发生）；当前尺寸走 `valueOf()` 回调——**件不持有被拖的那个元素**，谁被拖谁报当前值；跟手改界面走 `onResize`（每帧一次），松手/按方向键才走 `onCommit`（写设置并持久化）。这两下必须分开：拖一格存一次盘会把设置文件写爆。给读屏的那句名字走 `ariaLabel`。
- **谁在用**：侧栏宽度（原型 :1359-1387 那一套）与队列高度（:1402 起那一套）。**以前是两套各写各的**——边界、`.dragging`、收尾清理抄了两遍，改一处忘另一处就"一个能拖一个拖不动"；且只监听鼠标，键盘完全做不到。现在方向键 8px 步进、PageUp/PageDown 四倍步、Home/End 到两端，指针用 `setPointerCapture`，拖到窗口外松手也不卡在 dragging。

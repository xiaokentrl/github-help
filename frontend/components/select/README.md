# Select（`components/select/`）

- **这个件管什么**：多选一的下拉，走原生 `<select>`。状态：默认／悬停／焦点可见／禁用。两档形状（`size:'sel'` 设置面板那档、`size:'mode'` 工具栏那档）都在这一个件里，靠 class 分。
- **有哪些状态靠谁给**：选项文字、当前值、"这一项暂不可选"的说明全由调用方给（`options`／`value`／`ariaLabel`）；件里一个中文也没有。换整批选项时传 `update({options})`，件会重建再落值。禁用走 `disabled`（一传就是原生 `<select>` 整颗灰掉），灰了要说清在等什么——那句由调用方传 `title`，件只负责挂到控件自己上（人性化清单第 4 条）。
- **谁在用**：模式选择、语言选择、代理类型那几处。原型是 `.sel`（:394）与 `select.mode`（:91）两套平行样式，各自带一条 `:focus`——这里把两条 `:focus` 删了，焦点环交回 `styles/base.css` 那条全站规则。**这一件还挂着"待 M0 实测"**：原生下拉在两个平台弹出长得不一样，量出来确实对不上才换自绘（组件库规划.md 第 10 节第 4 条）。

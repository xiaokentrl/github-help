# ProgressBar（`components/progress-bar/`）

- **这个件管什么**：三档形状的进度——`global`（工具栏下那根 3px 全局线）、`bar`（块里 6px 条 + 下面一行小字，更新下载用的就是这档）、`score`（候选表行内 46×5 的评分条）。状态：确定（给 `value/max`）、不确定（`indeterminate:true`，不知道还剩几项时条子来回扫）、显隐（`show(true/false)`，靠 CSS 过渡淡入淡出，件里没有定时器）。
- **有哪些状态靠谁给**：那行小字（「3 / 8 · 正在写入」这类）由调用方传 `text`，件不持有文案；`text` 只允许 `kind:'bar'` 用，往另两档塞会当场抛错——全局线是绝对定位、评分条是行内，塞字就得包一层 div，一包逐屏比对立刻对不上。
- **谁在用**：全局那根线在各菜单执行任务时（原型 :704/:1701）；`bar` 那档是设置面板"立即更新"下面那块（:988-991）；`score` 是候选表的评分列（:1931）。**这条线的定位只许 `top:100%` 贴父元素下沿**，不许写像素——C3 当年修的就是写死像素导致线压在按钮上，原型 :76 那句注释还在。

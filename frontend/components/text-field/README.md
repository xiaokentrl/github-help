# TextField（`components/text-field/`）

- **这个件管什么**：搜索框那一个（原型 `.search` :67-70，高 30、宽 210）。状态：默认／焦点（走全站 `:focus-visible` 那一套，件不再自画）／**有内容时出现清空钮**／输入法组合中（`compositionstart`~`end` 之间不发过滤）。
- **有哪些状态靠谁给**：占位文字、清空钮的悬停说明都由调用方传（`placeholder`／`clearTitle`），件里一个中文也不写；过滤动作走 `onInput` 回调。禁用走 `disabled`（一传就是输入框与清空钮**两颗一起灰**，只灰一颗会让人以为清空钮坏了），灰了要说清在等什么——那句由调用方传 `title`，件只负责挂到输入框上（人性化清单第 4 条）。补的两样都在件内：① 拼音没打完不触发过滤（人性化清单第 11 条，原型没有这条——半截拼音发出去结果会乱跳）；② 一键清空回到全量（`Esc` 与点清空钮同一条路）。**无结果那句"没有匹配项，清空看看全部"不在这里**——那是第 4.14 条的 `EmptyState`，由视图层挂。
- **谁在用**：工具栏那颗搜索框（原型 :694）。将来类目名／域名／平台三种过滤共用这一件，只是 `onInput` 各接各的匹配逻辑。

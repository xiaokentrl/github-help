# ErrorBox（`components/error-box/`）

- **这个件管什么**：一条项为什么没成（红条），或"有备选方案"的那种黄条（`kind:'warn'`）。状态：默认／悬停（重试钮）／禁用（重试暂不能吃的时候，钮置灰并且要说清为什么）。样式逐字照原型 :227-229，四处颜色（`--red-soft`/`--line-soft-d`/`--error-fg`、黄条那三对）全走语义令牌。
- **有哪些状态靠谁给**：错误正文与"给人复制"的那串（接口名/错误码，等宽小字）由调用方传 `text`／`detail`；**重试必须有**——`retry:{label,onClick}` 少了当场抛错，按下去走的是调用方接的那条幂等路（原型 `resetTaskToWaiting` :3169），件自己不懂业务。禁用的原因走 `Button` 那颗的 `title`，也是调用方给。
- **谁在用**：详情面板那条错误横条（原型 :1936 一处）。将来队列行的失败原因要显示，也走这一件，别再抄一份红条。

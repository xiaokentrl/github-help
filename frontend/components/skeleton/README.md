# Skeleton（`components/skeleton/`）

- **这个件管什么**：等后端首帧时占位的扫光块。三档：`value`（详情指标那一格，60×12，跟原型同尺寸）、`line`（一整行文字，高 12 宽随容器）、`block`（整块占位，高 32 宽随容器）。状态：只有一档动画在跑／减弱动效下停住（`styles/base.css` 那条全局规则管着，件里不重复写）。
- **有哪些状态靠谁给**：给读屏的那句"正在加载"由调用方传 `ariaLabel`（件不持有文案）；要几行传 `lines`。**宽高不接受手填像素**——只认这三档名，每档的尺寸全部由尺寸令牌凑出来（见 `skeleton.css` 头上那段），想加第四档就得先在样式里加一档，逼人来这里登记一次。**`line`／`block` 这两档的"宽随容器"靠 `.skeleton-wrap-fluid` 撑着**（`display:flex`）：外层是默认的 `inline-flex` 时它是收缩适应，里面的 `width:100%` 会算成 0，两块占位直接看不见——状态矩阵里 `skeleton/line`、`skeleton/block` 两行量的就是这个宽度，谁删那一条 class 立刻红。
- **谁在用**：详情面板忙态（原型 :1916 那一格）、队列表格等首帧的行。原型那 60×12 是手写在样式里的，所以内容一变化就跳版——这就是第 4 节 4.10 说的"骨架跟真实布局对不上"。
